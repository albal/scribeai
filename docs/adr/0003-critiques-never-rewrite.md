# Critiques diagnose; they never rewrite

The PRD had Critiques offer "concrete suggestions for rewrites" (e.g. "replace 'really bad' with 'substandard'"). We deliberately dropped this: a Critique may quote the writer's own text and name the problem and principle at stake, but never supplies replacement wording, not even a single word, and there is no way to apply text from a Critique into the Document. ScribeAI is a critique partner, not a ghostwriter; the words in the Document stay the writer's own. Do not add rewrite suggestions as a "missing feature".
