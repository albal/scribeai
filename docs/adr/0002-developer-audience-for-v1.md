# v1 ships as an unsigned DMG for home users, with no setup wizard

The PRD promises "zero technical knowledge" setup: a first-launch wizard that silently installs Ollama. For v1 we instead let home users download an unsigned DMG from GitHub Releases: the app is ad-hoc signed so Apple Silicon will run it, but has no Developer ID signature and isn't notarized, so users approve it once in System Settings > Privacy & Security, following the install guide in the README and release notes. Developers can still build from source in Xcode. Users install Ollama themselves; the app only detects a missing Ollama and explains how to install it, and pulls the configured model with a progress bar. This avoids the cost of an Apple Developer account and the hardest, riskiest part of the PRD (unattended binary installation) until the core critique loop is proven. Developer ID signing, notarization and the wizard can be revisited once the one-time approval step proves a real barrier for non-technical writers.
